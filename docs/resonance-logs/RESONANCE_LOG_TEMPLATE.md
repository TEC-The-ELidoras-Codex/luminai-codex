## Notes for Users

### **When to Use This Template**

✅ Document a creative project lifecycle  
✅ Analyze a team sprint or project phase  
✅ Log weekly listening, reading, or media consumption patterns  
✅ Capture AI system training or emergence moments  
✅ Record cross-disciplinary collaboration events  
✅ Archive personal or collective learning cycles

### **Scoring Tips**

- **Φᴱ:** Think density and clarity. High scores = rich context + clear lineage.
- **φᵗ:** Think coherence. High scores = strong feedback loops + clear phase transitions.
- **ψʳ:** Think elegance. High scores = balanced hierarchy + meaningful repetition.

### **Interpretation Tips**

- R > 0.75 = Ready to share, document, archive
- R 0.5–0.75 = Stable; good for reflection or iteration
- R < 0.5 = Needs clarification or reframing

### **Export Options**

- **Markdown:** Save as `.md` for version control
- **Notion:** Copy structure into Notion database with formula field
- **Obsidian:** Use as frontmatter template with links to vault
- **JSON:** Convert to structured data for computational analysis
